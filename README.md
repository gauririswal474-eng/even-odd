# JavaScript - Check if a Number is Even or Odd

## Objective
A JavaScript program that checks whether a given number is even or odd.

## Logic
A number is even if it is divisible by 2 (`number % 2 === 0`), otherwise it is odd. An `if-else` statement is used to decide, and the result is printed with `console.log()`.

## Variables Used
| Variable | Value |
|----------|-------|
| number1 | 5 |
| number2 | 10 |
| number3 | 7 |
| number4 | 12 |

## Output
```
The number 5 is odd.
The number 10 is even.
The number 7 is odd.
The number 12 is even.
```
The results are printed with `console.log()` and also shown on the page.

## Files
- `index.html` - page structure, links the CSS and JS
- `style.css` - styling
- `script.js` - even/odd logic
- `README.md` - project description

## How to Run
Open `index.html` in a browser and press F12 to view the console output.
